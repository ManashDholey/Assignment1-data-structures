GenAI Assignment Task

This repository contains a collection of Python-based assignments focused on data structures and natural language processing (NLP). The code shows a structured learning project where each task explores core computer science concepts such as arrays, stacks, queues, trees, and algorithmic problem solving, while also covering practical NLP concepts like text processing and language-based analysis.

Overall, the project demonstrates hands-on programming practice, logical thinking, and implementation of fundamental data structures and AI-related problem solving in a clean, assignment-based format.
